This brief covers AI news from 2026-09-01 UTC.

Today's brief covers Nvidia's MediaTek investment, Anthropic's cloud deal, and new model releases.

## Nvidia invests $3.5B in MediaTek for custom AI chips

**What happened:** Nvidia announced a $3.5 billion investment in MediaTek via convertible bonds. MediaTek will adopt Nvidia's NVLink Fusion platform to help customers design custom XPUs that integrate into Nvidia-based data centers.

**Why it matters:** Developers can build custom accelerators that plug into Nvidia's rack-scale infrastructure, reducing reliance on off-the-shelf GPUs.

[Source: NVIDIA](<https://www.globenewswire.com/news-release/2026/08/31/3353306/0/en/nvidia-and-mediatek-deepen-long-standing-partnership-to-build-ai-edge-to-cloud-computing-platforms.html>)

## Anthropic signs $35B cloud deal with Lambda

**What happened:** Anthropic signed a $35 billion cloud-computing deal with Nvidia-backed Lambda for a Texas data center developed by Hut 8, covering about 350 megawatts of capacity.

**Why it matters:** Anthropic secures massive compute for Claude, easing GPU bottlenecks for its AI services.

[Source: CNA](<https://www.channelnewsasia.com/business/anthropic-signs-35-billion-cloud-deal-nvidia-backed-lambda-source-says-6353306>)

## DeepSeek releases V4-Flash-Vision open weights

**What happened:** DeepSeek published open weights for DeepSeek-V4-Flash-Vision-Exp, a 305B-parameter multimodal model, under an MIT license. The 168GB repository includes reference inference code.

**Why it matters:** Developers can run and fine-tune a frontier vision model locally, enabling multimodal agents without API dependency.

[Source: RuntimeWire](<https://runtimewire.com/article/deepseek-publishes-v4-flash-vision-open-weights>)

## Runway unveils Solaris, an interface world model

**What happened:** Runway introduced Solaris, the first model in a new family called Interface World Models. It generates apps and websites in real time, frame by frame, without an intermediate code representation.

**Why it matters:** Could eliminate the design-to-code step, letting developers build interactive interfaces directly from models.

[Source: Runway](<https://runwayml.com/news/research/introducing-solaris>)

## Perceptron AI launches Isaac 0.5 robotics model

**What happened:** Perceptron AI released Isaac 0.5, a 36B-parameter open-weight embodied foundation model that combines video understanding, reasoning, and robot control. It outperforms open rivals like π0.5 and GR00T N1.7.

**Why it matters:** Robotics teams get a frontier open model to control robots or integrate into planning systems, reducing need for proprietary solutions.

[Source: IT Tech Pulse](<https://ittech-pulse.com/news/perceptron-ai-launches-isaac-0-5-a-frontier-open-weight-robotics-model/>)

## Nvidia unveils Nemotron 3.5 Lightning and NeMo Switchyard

**What happened:** Nvidia released Nemotron 3.5 Lightning, a 30B-parameter MoE model for agentic workloads, and NeMo Switchyard, an open-source library for routing requests to the best model in multi-agent systems.

**Why it matters:** Developers can build efficient multi-agent systems with smart routing across open and proprietary models without rewriting apps.

[Source: Future Tech Markets](<https://futuretechmarkets.com/markets/nvidia-nemotron-3-5-lightning-and-nemo-switchyard-deliver-faster-smarter-more-efficient-agentic-ai-25/>)

## EU designates ChatGPT as a search engine under DSA

**What happened:** The European Commission classified ChatGPT as a Very Large Online Search Engine under the DSA, alongside Reddit and Roblox as VLOPs. ChatGPT has 159M monthly EU users.

**Why it matters:** ChatGPT now faces strict EU compliance: systemic risk assessments, transparency reports, and data access for researchers, affecting how it operates in Europe.

[Source: TNW](<https://thenextweb.com/news/hatgpt-reddit-roblox-dsa-designation>)
